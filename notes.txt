DFS implementation
- Keep track of Boggle board, with 0,0 (upper-left corner) being the first starting point
    - start at first row then work through col
    - Starting point will dictate the valid directions for traversal
- recursively travels to valid tiles
    - valid defined as: not out-of-bounds and not have previously visited
    - movement is NEWS, diagonal paths included
        - N = r-1, c
            - NE = r-1,c+1
            - NW = r-1,c-1
        - E = r, c+1
        - W = r, c-1
        - S = r+1, c
            - SE = r+1,c+1
            - SW = r+1,c-1
- end-points:
    - no more valid paths on board
        - level 2, tiles visited and bounds in all 8 directions
    - no more children nodes in trie
        - level 1, trie structure of valid words determines end of board pathing
            - as no child node, means no words with the current string as prefix
    - at endpoints, reset visited up to last branch (uncertain implementation)
